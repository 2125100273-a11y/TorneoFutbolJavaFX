PROYECTO: TorneoFutbol
IDE: Apache NetBeans 29
TECNOLOGIA: Java 11, JavaFX 13, FXML y Maven.

IMPORTAR:
1. Descomprime TorneoFutbol.zip.
2. En NetBeans selecciona File > Open Project.
3. Selecciona la carpeta TorneoFutbol (la que contiene pom.xml).
4. Espera a que Maven descargue JavaFX.
5. Clic derecho al proyecto > Clean and Build.
6. Ejecuta Run Project.

NOTAS:
- No utiliza MariaDB ni base de datos.
- Los registros se mantienen únicamente en memoria mientras la aplicación está abierta.
- Incluye pestañas para Administrador, Equipo, Jugador, Partido, Resultado y Posiciones.
- Las validaciones y mensajes se actualizan al escribir, borrar o pegar.
- Guardar agrega un renglón a la lista en memoria; no persiste información.
- Editar y Eliminar son demostrativos y no alteran los registros.
